# Rheinmetall Control Board App

Rheinmetall Control App is the official companion app for the Rheinmetall controller board. Using a wireless Bluetooth connection, it allows you to adjust output voltage, fine-tune PWM frequency and duty cycle, and customize RGB lighting styles directly from your device.

## Downloads
* **Android App (APK):** [Download Latest Release](https://github.com/danieladven0772-lgtm/Rheinmetal-Control-Board-App/releases/latest)
* **3D Enclosure / Case Files:** [Download on Printables](https://www.printables.com/model/1903467-board-decoy-pd-trigger-5-15v-bp-v1)

## Quick Start Guide
1. **Connect Hardware:** Wire your load and cooling fan to the board before connecting power.
2. **Power On:** Plug a compatible USB Power Delivery (PD) charger/adapter into the board.
3. **Install App:** Download and install the `.apk` file from the link above.
4. **Pair & Control:** Enable Bluetooth on your phone, open the app, connect to the Rheinmetall board, and adjust your voltage, PWM frequency/duty cycle, and RGB lighting.
